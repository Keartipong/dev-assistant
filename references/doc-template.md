> ยึดกฎกลางใน `SKILL.md#Rules` เขียนกระชับ อ้างอิง `ไฟล์:บรรทัด`

## 1. เขียนเอกสารจากโค้ด (Code->Doc)
```markdown
### [ชื่อ Endpoint / ฟังก์ชัน / Component]
- source: `path/to/file:line`
- purpose: [สรุปหน้าที่ 1 บรรทัด]
- auth_roles: [สิทธิ์ที่ต้องใช้ หรือ public]

#### Input / Params / Props
| ชื่อ | ชนิด | จำเป็น | ค่าเริ่มต้น | เงื่อนไข/ข้อจำกัด |
| :--- | :--- | :--- | :--- | :--- |
| `field` | `string` | ใช่ | - | `max 100 chars` |

#### Output / Response / Errors
| สถานะ/กรณี | โครงสร้างข้อมูล | คำอธิบาย |
| :--- | :--- | :--- |
| `200 OK` | `{ data, message }` | สำเร็จ |
| `400/403` | `{ error_code, message }` | ข้อมูลผิด / ไม่มีสิทธิ์ |
```

## 2. ตรวจเอกสารเทียบโค้ด (Doc<->Code)
- เทียบชื่อพารามิเตอร์, ชนิดข้อมูล, required/optional, default value, HTTP method/URL, status code, สิทธิ์ auth
- รายงานเฉพาะจุดที่ไม่ตรงกันในตาราง (`≤ 15 รายการ`, รายการละ `≤ 1 บรรทัด`):

| หัวข้อ | ข้อมูลในเอกสาร | พฤติกรรมในโค้ดจริง (`ไฟล์:บรรทัด`) | การแก้ไขที่แนะนำ |
| :--- | :--- | :--- | :--- |
| `[ชื่อฟิลด์/สถานะ]` | `[ค่าในเอกสาร]` | `[ค่าในโค้ดจริง]` | `[แก้เอกสาร หรือ แก้โค้ด]` |
